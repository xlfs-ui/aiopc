# 活动提醒与政策官方来源

## 活动倒计时

- 登录后的所有页面展示本人已报名且未结束的活动，包括日期、时间、地点和倒计时。
- 登录、报名成功、重新打开页面、切回浏览器标签时更新；页面可见时每分钟刷新，跨日自动更新。
- 使用服务端北京时间，明天、今天及已经开始分别提示；有明确结束时间的活动结束后不再提醒。
- 仅根据当前登录会话读取本人报名记录，切换账号或退出会清空提醒。此功能为站内提醒。
- 时间仅写文字、未提供明确结束时刻时，当天保留提醒，次日移除。提醒读取失败时明确提示并提供重试。

## 官方参考

- 政策卡片、详情和问答检索结果提供“查看官方原文”，在新标签打开。
- 管理员编辑政策时可维护官方原文链接，只接受 HTTPS 的 gov.cn 政府域名。
- 默认四项指引补充省级高龄津贴文件、国家政务服务平台上城区连续就读居住证事项、杭州市低保材料说明、退役军人事务部优待证政策解读。
- 地区、分类事项与全国性解读的适用范围写入来源名称。参考链接不代表本站摘要是正式政策文件，具体以原文及属地主管部门现行口径为准。
- 原高龄津贴默认摘要和步骤改为主动发放、异议核实补发；不覆盖管理员已经改写的摘要与步骤。
- 演示指引无对应正式政策时保留明确提示，不虚构官方原文。

## 数据升级

SQLite 和 PostgreSQL 升级至 schema v4，新增 policies.source_url；启动时为未填写链接的原始四项政策补充参考并同步检索索引。账号、工单、活动、报名及演示数据保持。
