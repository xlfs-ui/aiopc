# 社区服务视觉与阅读优化

## 阅读

- 原界面中多处 7–11px 的正文、提示和手机辅助文字已调整到可随根字号缩放的 rem 单位。
- 默认“舒适”模式：根字号 18px，主要正文约 18px，常见辅助文字约 14.4–16.9px；标题保持明确层级。
- 全站右下角“阅读设置”可选择标准（16px 根字号）、舒适（18px）、大字（20px），支持增强文字对比、减少动态效果。
- 设置只保存在当前浏览器 `community-display-v1` 本地偏好，不上传账号或服务器。损坏或被限制的本地存储不会影响登录。
- 表单、搜索、验证码和按钮留出更充足高度；手机布局调整为单列或两列，表格保留横向滚动。原先随 SVG 缩小的民情图表日期移到 HTML 中显示。

## 配色

以社区服务为主题，使用深翡翠侧栏、湖蓝与青绿主视觉、暖金提示、淡紫分类。正文使用深蓝灰，次要信息加深，区分等待、处理中、待确认与完成状态。

登录、服务导航、政策卡片、活动、聊天、知识文档、民情看板与报告统一使用新的视觉层次。色彩辅助识别，状态仍保留文字，不单靠颜色表达。

## 动效

- 页面切换时渐入，卡片悬浮抬升与指针光晕。
- 主按钮点击波纹、快捷服务图标反馈。
- 服务入口及登录主视觉柔和渐变漂移，保留民情雷达与趋势线绘制。
- 阅读偏好面板开合过渡、加载骨架和状态提示。

指针反馈使用事件委托及 requestAnimationFrame，触摸设备不运行鼠标光晕。系统 `prefers-reduced-motion` 或用户“减少动态效果”启用后，停止动画及过渡，保留正常操作和焦点提示。

本次是前端优化，无新增运行依赖或数据库结构，不需要变更 Neon 数据；通过 GitHub 更新源码、Render 重建前端后生效。生产构建包含 Vue / TypeScript 检查；不等同于已完成所有屏幕尺寸的人工视觉验收。
