# 数据库演示样本

批次：`community-demo-v1`。这是用户明确要求写入数据库的虚构功能样本，与民情页面原来的临时“演示效果”开关不同。

## 内容

- 近 180 天共 390 件工单，覆盖停车、照明、噪音、虫害、给排水、道路及设施，不同处理状态与优先级。
- 870 条咨询分类，用于咨询走势和热门主题；不包含真实对话内容。
- 4 个演示小区、12 个虚构居民账号及地点关联。虚构账号的密码字段为禁用标记，不能登录。
- 6 个未来活动、40 条演示报名；原管理员账号有一部分演示工单及一项报名，可在居民模式体验“我的工单 / 已报名”。
- 6 条演示办事指引、4 份演示文档（3 已发布、1 待审核），已发布文档建立全文检索索引，不自动请求付费嵌入 API。
- 近 7 / 30 / 90 天的 3 份报告，明确注明含演示样本。

所有地点、活动、文档和工单均带演示标识；分析页面与报告另行提示样本性质，不得用于实际调度或作为官方办事条件。原有用户、业务记录、文档和账号密码不改写。

## 一次性导入

本地已有依赖时，可在激活 Conda 环境后于根目录执行：

```powershell
python backend/database.py seed-demo
```

需事先创建管理员。脚本在事务内追加记录，以 `snapshots.id=100001` 保存批次标记，重启或重复执行不会重复添加；初始化冲突则回滚本批次，保留已有记录。报告在基础数据提交后补建，重复执行时只补缺失报告。

云端通过私密配置 `DEMO_SEED_BATCH=community-demo-v1` 在 Render 启动时执行。日志 `Sample dataset ready` 返回实际入库数量与报告数量。完成后移除启动设置；样本仍保存在 Neon。

```powershell
python scripts/render-deploy.py seed-demo
python scripts/render-deploy.py remove-demo-seed
```

上述云端命令读取根目录 `.env.deploy`，不要把凭据上传。管理员 API `/api/civic/sample-status` 可查看批次是否安装。

未来如需清理，需按该批次固定标识核对依赖后操作，不能删除整库或混删真实数据。本次不自动提供无确认的批量清理入口。
